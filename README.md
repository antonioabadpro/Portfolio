## 📌 Sobre el Proyecto

Portfolio web personal diseñado y desarrollado desde cero con una arquitectura frontend ligera, reactiva y ultra optimizada, sin sobrecargas de frameworks innecesarios. El objetivo es ofrecer una experiencia de usuario fluida, accesible y moderna, destacando proyectos de ingeniería de software, trayectoria académica y habilidades técnicas.

### ✨ Características Principales

* 🌓 **Modo Oscuro / Modo Claro Dinámico:** Selector de tema persistente en `localStorage` con detección automática de preferencias del sistema.
* 🌐 **Soporte Bilingüe (i18n):** Sistema de traducción en tiempo real (Español / Inglés) implementado en JavaScript vanilla sin recargar la página.
* ⚡ **Ultra Rendimiento & Core Web Vitals:** Carga instantánea, imágenes optimizadas en formato `.webp`, maquetación con CSS moderno y cero dependencias pesadas.
* 📱 **Diseño 100% Responsive:** Adaptación fluida para dispositivos móviles, tablets y monitores ultrawide mediante Tailwind CSS.
* 🛠️ **Carruseles de Stack Tecnológico:** Navegación por scroll horizontal interactivo con detección dinámica de desbordamiento y botones de control.
* 📩 **Generador Inteligente de Correo:** Integración directa con plantillas personalizadas de Gmail y enlaces `mailto:` según el motivo de la consulta.
